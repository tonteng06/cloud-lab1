Cloud Computing

Cloud computing means renting computing resources such as servers, storage, databases and networking over the internet instead of buying and maintaining my own hardware. I only pay for what I use, and I can scale up or down in minutes when demand changes. The provider takes care of the data centers, power and physical security, so I can focus on building applications. Because the services are reachable from anywhere with an internet connection, teams can collaborate easily and deploy projects around the world quickly. Popular providers include AWS, Microsoft Azure and Google Cloud.

Cloud Services

IaaS

Infrastructure as a Service gives virtual machines, storage and networks that I manage myself.

Example: Amazon EC2

PaaS

Platform as a Service provides a ready environment to build and run apps without managing servers.

Example: Google App Engine

SaaS

Software as a Service delivers a finished application to users through the browser.

Example: Google Docs
